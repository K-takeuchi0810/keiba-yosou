## 私の検証の過大主張 (検証監査人の指摘、受け入れて訂正済み)

1. **A1→B→A2 の連続生成は同語反復に近い。** generator の命令列が両状態で同一なので
   一致は恒等式。実際に測れたのは「85 秒の窓でデータが動かなかった」ことだけ。
   無影響の主たる証拠は **diff stat + import graph** であり、HTML 比較ではない。
2. **「bit-identical」は過大主張。** 生成時刻の 1 行を除いた一致であり、除外した時点で
   完全一致ではない。正しくは「生成時刻行を除いて一致」。
3. **`prediction_log` 比較も同語反復。** `--log-predictions` を付けずに回したので
   書き込み自体が起きない。
4. **「generator は通知層を 1 つも import しない」は不正確。** `web/generator.py:69,79` が
   `scripts.notify_discord` を遅延 import する。正確には
   「`auto_predict` / `notify_dedup` を import しない」。
5. **自分の保持期間テストが同語反復だった。** 境界を `RETENTION_DAYS` から計算していたので
   `RETENTION_DAYS = 0` でも通った。リテラル 14 に修正。
