## 依頼 4 点への回答 (すべて自分で実測)

**1. init_score 実装の正否 → 正しい。** LightGBM 4.6.0 で合成データ検証: `init_score=-2.0` 定数で学習 → `predict(raw_score=True)` の平均 −0.067 (init は含まれない、`boost_from_average` は init_score 存在時にスキップ)、真の margin 0.8·x に対し回帰傾き 0.885、save/load 往復差 0.0。`fit()` の `init + margin` と `collect()` の `logit(P_T10) + predict(raw_score=True)` は仕様に整合。検証セットの早期停止指標も valid 側 init_score 込みで計算される。

**2. best_iteration=27 の意味 → 「補正余地が無い」が主因。ただし比較対象は T−10 ではなく確定オッズ。**

2021-2025 の勝ち馬で `win_odds/10 == 確定払戻/100` が **99.5 / 99.8 / 99.8 / 99.7 / 99.7%**。**学習・検証の init_score は確定オッズそのもの**。docstring と PREREG の「確定オッズではない、47.8% 不一致」は **2026 年のみの現象** (2026 全体 77.4%、評価窓 40.8%) を学習期間に誤って一般化している。

検証 94,709 頭での LogLoss 差をレース単位 bootstrap: **−0.000084、95% [−0.000193, +0.000019]** → 0 をまたぐ。**確定オッズに対して 30 特徴は N=9.5 万でも有意な残差を持たない。** これは「学べていない」ではなく「学ぶものが無い (対確定オッズ)」。ハイパーパラメータは原因ではない。

**3. skew の効き方 → 向きが docs と逆。**

同一 626 レースで T−10 implied の LogLoss 0.21351 に対し `win_odds` implied は **0.21110 (差 −0.00241、95% [−0.00405, −0.00097]、0 を含まない)**。**学習の基準市場は運用の基準市場より強い。**

T−10→win_odds の |Δlogit| は平均 0.253 / sd 0.329、モデル補正 margin の sd は **0.0807**。つまり「T−10 と確定の間で市場自身が動く量」が「モデルの補正全量」の 4 倍で、モデルは確定市場の残差を学んだので T−10 の誤価格を捉える設計になっていない。

**主要仮説 β₂ の検出力**: CI 半幅 1.281 × sd(margin) 0.0807 = **0.103 logit が最小検出可能 shift**。「対 T−10 で情報無し」は **未検出であって否定ではない**。

一方 **金額の結論は逆に強まる**: 払戻は確定オッズで行われるため、**確定市場に足せない特徴は原理的に回収率エッジを作れない**。「負の結果はそのまま読める」は金額については正しく、主要仮説については誤り。

**4. 「30 特徴を外す」の妥当性 → 支持する。根拠は β₂ ではなく検証 N=9.5 万の対確定オッズ結果。**

gain 上位は t_winrate 9.2% / s_winrate 9.0% / j_winrate 8.8% / t_runs 7.9% / w_abs 6.5% / j_rides 6.2% で、いずれも市場代理変数。

補正の向きに注意: 2026 fresh で corr(margin, logit P_T10) = **−0.179**、帯別 margin 平均は 0-5% 帯 +0.020 / 30%+ 帯 −0.027 だが、T−10 の実測ずれは 0-5% 帯 −0.004 / 30%+ 帯 +0.041 と **逆向き**。モデルは T−10 に残る favorite-longshot bias を **強める**方向に押している。これは特徴の価値ではなくカウント特徴の域外外挿の産物である可能性が高い。

◎ 相当 (offset top1) が市場 1 番人気と一致 **603/626 (96.3%)**、乖離は 23 レースのみ。edge の mean|e| 0.311pt / max 3.749pt / >5pt 0 頭を再現 (**事前登録の購入条件 5pt は、確定オッズを基準に学習した補正では構造的に届かない閾値だった**)。
