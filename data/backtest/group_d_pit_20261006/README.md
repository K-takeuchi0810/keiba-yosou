## 残っている仕様 (事前登録 §2 D は概略だけ。探索の前に §8-4d として固定が要る)

事前登録 §2 D: `class_delta = 前走 Performance Rating − 今回クラスの要求 Performance`、`class_move`、`class_delta_x_move`、
反証の条件「`class_move` 単独と比べて `class_delta` の追加係数が増えない」。次が未定:

2. **評価値の版**: Group A の凍結した仕様 (S1V1W0、秒 / km の残差、P3) をそのまま使うか

   `class_move` を局外の列として主検定の式に入れる (`[log P_market, class_move, S]`) のが反証の条件と整合する (C′ の教訓: 主効果を局外の列に)
