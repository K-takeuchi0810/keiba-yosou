## 期待値の採り方

- JRA 公式サイトの「過去レース結果検索 → 開催 → 全てのレースを表示」の各レースの見出しにある競走条件の表記
  (例「3歳以上1勝クラス」「2歳新馬」「3歳未勝利」「3歳以上オープン」、重賞はグレードの表記) を写す。出典の URL / CNAME と
  取得時刻を記録する
- 表記から次の 2 つを期待値にする
  - **canonical class**: 新馬 → 701 / 未勝利 → 703 / 1勝クラス → 005 / 2勝クラス → 010 / 3勝クラス → 016 /
    オープン・リステッド・重賞 → 999
  - **最若年**: 表記の先頭の年齢 (「2歳」「3歳」「3歳以上」→ 3、「4歳以上」→ 4)

## 判定の規則 (固定)

- raw の RA の位置 635 (最若年条件) の値が、全レースで canonical class の期待値と **完全一致**
- 最若年が 2 歳なら位置 623 (2 歳条件)、3 歳 (3 歳限定・3 歳以上) なら位置 626 (3 歳条件)、4 歳以上なら位置 629 (4 歳条件) が、
  位置 635 と同じ値であること (最若年の欄の意味の確認)
- 1 レースでも食い違えば不合格。不合格なら凍結せず、Group A のクラスの表は作らない (原因を記録して外部の指示者に諮る)
- 判定は raw だけで行う。DB の races と突き合わせるのは開催日・競馬場・レース番号・距離 (同じレースであることの確認) だけ
