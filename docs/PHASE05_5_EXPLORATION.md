## Group A — 探索の前に固定すること (2026-10-05、探索の結果を見る前に書いた)

### A-0. 固定の前提 (探索しない)

事前登録の §8-4b と §8-4b-2 のとおり。要点:

- 時計: `finish_time` は MSSt を秒に復号 (`分 × 60 + 秒 + 1/10 秒`)。0 は NaN。障害 (`track_type_code` 51 以上。§8-4b-2 で統一) は対象レースからも
  過去走からも除く。過去走は JRA (track 01〜10)・`races.data_div = 7`・平地・時計のある走だけ
- ペース補正なし。クラスは馬場差の推定の局外の補正としてだけ使い、評価値から引かない (2a)
- 成分は 4 つ (`perf_rating_last` / `perf_rating_best3_365` / `perf_rating_trend_365` / `perf_rating_rank_in_race`)、期待される
  符号はすべて正。過去走は対象日の 365 日前から前日まで (対象日の走は使わない)
- 欠損は標準化した後の 0。指示変数は使わない。合成は §8-4 の手順 3〜4 (逆符号の成分は重み 0)
- `perf_rating_rank_in_race` の母集団は、対象レースの **選択集合** (返還の対象 1/2/3 を除き `win_odds > 0` の馬) のうち
  `perf_rating_best3_365` が欠損でない馬

### A-1. 補正テーブルの形 (固定)

**コースのセル** = (競馬場 `track_code`, `track_type_code`, 距離)。`track_type_code` は芝 / ダートと内回り・外回り・直線を区別する。

**レースの代表タイム (固定)**: 勝ち馬 (確定着順 1) の走破タイム。同着なら同じ値。1 レース 1 観測で、頭数の多いレースが
推定を支配しないようにする (外部の指示者の要件)。勝ち馬の時計が NaN のレースは推定から除く。

**単位 (固定前処理 P1、2026-10-05 外部の指示者の決定)**: 時計の模型・補正・残差は、すべて **秒 / km** (走破タイム ÷ 距離 km) で扱う
(秒で加算すると、同じ補正の意味が距離で変わるため)。

**標準タイムの模型 (レース単位の最小二乗、推定期間のレースだけ)**:

    勝ち時計_r / km_r = a[コースのセル] + g[芝ダ × 馬場状態 (良・稍重・重・不良)]
                       + c[canonical class] + d[年齢の制限の区分] + ε_r          (すべて秒 / km)

- `c` (クラス) と `d` (年齢の制限の区分、固定前処理 P2) は **局外の補正 (nuisance)**。`ε_r` (馬場差の材料) を作るためだけに使い、
  **馬ごとの評価値からは直接引かない** (2a の契約。若い世代の限定戦が一般に遅いことを「その日の馬場が重かった」と誤認しないためで、
  能力の差そのものは評価値に残す)
- **評価値の基準** には `a[セル] + g[芝ダ × 馬場状態]` だけを使う
- **年齢の制限の区分の導出 (固定、1 つの関数)**: 凍結した表の `c2〜c5` の「000 でない欄」の並びで決める。
  `c2 だけ` → 2 歳 / `c3 だけ` → 3 歳限定 / `c3・c4・c5` → 3 歳以上 / `c4・c5` → 4 歳以上。**これ以外の並びは推測せず欠損**とし、
  そのレースは標準タイムの推定と馬場差の材料から除く (そのレースの走の評価値は、`a + g` と他のレースの馬場差で作る)。
  2021-2025 の表では 4 つの並び以外は 0 件 (平地: 2 歳 3,217 / 3 歳限定 5,254 / 3 歳以上 4,867 / 4 歳以上 3,328)
- 勝ち時計 (レース単位) には裾の処理を当てない (P3 は下の馬単位の残差だけ)

**疎なセルの扱い (固定)**:

1. 推定期間のレースが 20 以上あるセルは、そのセルの水準を使う
2. 20 未満のセルのレースは、セルを (`track_type_code` の芝 / ダートの区分, 距離) の **共有の水準** に入れる。共有の水準は、
   その種類の疎なセルのレースだけで推定する
3. 共有の水準も 20 未満なら、そのレースの走は **評価値を持たない** (欠損)。推定期間に無いセル (例: 2025 にだけ現れる距離) も同じ
4. 疎なセル・共有の水準・評価値を持たない走の件数を、年別に記録する

### A-2. 探索する候補 (12 通り、ここに無いものは試さない)

| 軸 | 候補 | 内容 |
|---|---|---|
| 尺度 S | S1 / S2 | S1: 残差 (秒 / km) をそのまま使う。S2: 残差を、推定期間の (芝ダ, 距離の帯) ごとの馬単位の残差 (裾の処理の後) の SD で割る (帯: 1400 未満 / 1400〜1799 / 1800〜2199 / 2200 以上) |
| 馬場差 V | V0 / V1 / V2 | V0: 馬場差を使わない。V1: 同じ日・同じ競馬場・同じ芝ダのレースの `ε_r` (秒 / km) の **平均**。V2: 同じく **中央値**。どちらも 1 レース 1 観測で、**その走のレース自身を含める** (Beyer 型の慣行。件数の下限 3 と整合)。その日のその区分のレースが 3 未満なら 0 |
| 斤量 W | W0 / W1 | W0: 斤量の補正なし。W1: 推定期間の走で、同じ馬の中で (馬ごとに平均を引いて) 斤量 1 kg あたりの残差 (秒 / 1000 m) を最小二乗で推定した係数で補正する。基準は 55 kg。**ハンデ戦 (`weight_type_code = 1`) の走は推定から除く。推定した係数が 0 以下 (重いほど速い = 物理と逆) なら W1 は無効で、その候補は W0 と同じ扱いにする** (逆符号の係数は成長・昇級の代理を評価値に埋め込むため。2026-10-05 prediction-logic の指摘) |

馬の 1 走の評価値 (速いほど大):

    残差 (秒 / km) = 走破タイム / km − (a[セル] + g[芝ダ × 馬場状態]) − 馬場差 − w × (斤量 − 55)
    残差' = clip(残差, −3.0, +3.0)                                       (固定前処理 P3)
    評価値 = − 残差' ÷ 尺度 (S1 なら 1、S2 なら帯の SD)

(V0 なら馬場差 0、W0 なら w = 0。`c` と `d` は引かない)

- **固定前処理 P3 (裾の処理)**: 馬ごとの過去走の残差だけを **±3.0 秒 / km で対称に clip** する (大差負け・追うのをやめた走など
  1 走の極端な値が 365 日の履歴を支配しないための、影響の有界化)。標準タイムの推定・馬場差の推定に使うレース単位の勝ち時計には
  当てない。±3.0 は 2024 の dry run や 2025 を見て変えない。感度を見る場合は別の探索的な記録に留め、主仕様は変えない
- P1 / P2 / P3 は **12 の候補すべてに共通の固定前処理** で、探索の軸に足さない

- W1 は、斤量がクラス・ハンデで能力と相関するので偏りうる (同じ馬の中でも、斤量は馬齢・基礎重量の改定・昇級で時間とともに増え、
  その間に時計も速くなる。prediction-logic の実測で馬の中の斤量の偏差と時間の相関 +0.354)。係数は 0 側 (過小) か逆符号に偏りやすい
- V1 / V2 は、その走のレース自身の `ε_r` を含むので、その日の区分のレースが k 本なら、勝ち馬の評価値はそのレースの残差の 1/k ぶん
  0 側に縮む (k = 3 で 1/3)。この偏りを承知で含める側に固定する

### A-3. 選択の基準 (固定)

- **2 分割の交差 (2022 ⇄ 2023)**: 一方の年だけで補正テーブル・(W1 なら斤量の係数)・(S2 なら SD)・標準化・合成の重みを推定し、
  もう一方の年の対象レースで、条件付きロジット `logit(P_market) + S` の S の係数の z 値 (β / ヘッセ行列の SE) を出す。
  2 つの向きの z の平均が最も大きい候補を選ぶ
- 同点の扱い (全順序。2026-10-05 validation の指摘で固定): z の平均が最良の候補との差 0.25 未満の候補の集合を作り、その中で
  (1) 既定 (V0 / W0 / S1) でない軸の数が最も少ない → (2) V の順位 (V0 < V1 < V2) が最も小さい → (3) W の順位 (W0 < W1) →
  (4) S の順位 (S1 < S2) の順で 1 つに決める。集合は **最良の候補との差** で作る (連鎖させない)。W1 が無効 (係数 ≤ 0) の候補は
  W0 の候補と同じものとして数え、二重に数えない
- 2024 は選択に使わない (§8-4 の手順 5 の dry run = 2022-2023 で推定して 2024 で通す、をパイプラインの点検として行い、
  結果を記録するだけ)。**2022 ⇄ 2023 の交差の結果と選んだ候補をこの台帳にコミットしてから、2024 の dry run を走らせる**
- 交差 (1 年だけで推定) と最終 (2022-2024 の 3 年で推定) では疎なセルの率が違う (validation の実測: 1 年推定でセル 20 未満の
  レース 7.2% (2022) / 9.4% (2023)、評価値なし 2.9% / 2.8%。3 年推定で 1.1% / 0.6%)。交差は最終と別の条件を測っているので、
  候補ごとの評価値なしの件数を年別に必ず残す
- 探索のデータの読み込みは、コードで **2024 年以前のレースだけ** を通す (2025 の行が表と DB に同居しているため。テストで固定する)
- 選んだ後の最終の推定は 2022-2024 全部で行い、凍結物 (§8-4 の手順 6) を MANIFEST に残す
- 学習期の中では、補正テーブルが各行から見て未来の走も含むので、交差の z はやや楽観側になりうる (台帳に記録する)
