# Phase 0.5-4B — T−10 市場の取得元に対する感度分析 (2026-09-26)

**これは 4B の再判定ではなく感度分析。** 0B30 と 0B31 のどちらが正しいかは決めていない。
モデル (4B の `predictor/market_offset_model.txt` / `fundamental_model.txt`)、閾値、評価集合の規則は
4B と同じものを各系列にそのまま当て、**入力の T−10 市場だけ** を差し替えた。
背景は `docs/LIVE_INGEST_DATA_INTEGRITY_AUDIT.md` 3-bis。

- スクリプト: `scripts/t10_source_sensitivity.py`
- 成果物: `data/backtest/src_sensitivity_20260926/` (既存の 4A/4B の JSON・baseline は上書きしていない)
- 評価窓: 2026-05-09〜08-31 (4A/4B と同じ)。DB は mode=ro、コードは main `491d2e6`

## 系列

- 名前が二重の raw (`*.jvd_*.jvd`、1,980 本) はすべて 0 バイトで、除外しても影響は無い

**事前に固定した読み方** (結果を見る前にスクリプトに書いた):
判定可能 = 鮮度内のレース数が original_mixed の 50% (313) 以上。
「結論が同じ」= 主要仮説の合否・金額の判定・比 ≥ 1.75 が 0 頭か・棄却条件、の 4 つが一致。

### 集合の違いの原因: DB の取り込み漏れ

- 7/04・7/05・7/11・7/12 の 0B31 は raw に 368 本あるが、**DB の odds_snapshots に 1 行も無い**
  (backfill は 6/28 まで、ライブの取り込みは 7/18 から)。raw 系列はこの 131 レースを加える
- 8 月の 0B31 も raw 978 本に対し DB は 697 (同じ秒の上書きと未取り込み)

## 結論 (固定した書き方に照らして)

- **判定可能な 3 系列 (original_mixed / raw_mixed / raw_0B31) で結論は同じ**: 主要仮説は不合格
  (区間が 0 を含む)、金額は判定不能 (購入条件 0 頭)、比 ≥ 1.75 は 0 頭、棄却条件は該当なし。
  → 4B の否定的な結論は、**判定できた取得元の構成に対しては頑健**
- **raw_0B30 と matched_same_state は判定不能** (coverage 不足)。否定にも肯定にも使わない。
  したがって「matched_same_state で差が消えるか / 残るか」は判定できない
- 共通の集合での比較では、取得元による差は β₂ で 0.05 以下。結論を左右する大きさではない
- 4B の結論は **mixed-source 市場の結果** として記録しておく (解釈の修正)。ただし判定可能な系列の間では結論は変わらない

## 残る留保

- 0B30 だけ・同一状態だけの系列は 8 月 1 か月分しかなく、検出力が無い
- DB の取り込み漏れ (7 月前半) と同じ秒の上書きは、評価の結論は変えていないが、
  PIT データセットの凍結前に直す必要がある (DATA_PROVENANCE_DEFECT)
- 4A (旧 30 特徴) のモデルは再実行していない (4B が同じ評価集合での後継で、結論も同じため)
