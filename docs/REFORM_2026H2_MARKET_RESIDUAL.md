# 改革案 2026-H2: 市場残差アーキテクチャへの全面転換

作成: 2026-08-22 / 起点 branch: `fix/fresh-odds-recovery-and-filter-suspension`
位置づけ: 今後の精度・回収率向上の**憲法**。既存の F3 設計
(`docs/F3_MARKET_RESIDUAL_DESIGN.md`、ユーザ合意 4 制約) を上位互換で包含し、
矛盾する場合は F3 設計と 4 制約が優先する。

## 1. 診断 — なぜ回収率 65% なのか (全て 2026 実測)

| 基準 | 2026 (〜8/16) 実測 | 意味 |
|---|---|---|
| 1番人気ベタ買い | 2,232 戦 / **79.0%** | 市場に従うだけの回収率 (≒ 控除率どおり) |
| 本モデル ◎ベタ買い | 1,460 戦 / **65.3%** CI[57.8,72.8] | 市場より **−14pt** |
| 本モデル 買い候補 | 142 戦 / **53.4%** CI[30.4,80.1] | 絞るほど悪化 |

**核心の事実: モデルが市場と意見を違えるとき、平均して市場が正しい。**
「もっと良い勝ち馬予想」を公開情報 (JV-Data) で作る努力は、スタート地点が
市場追従より 14pt 後ろにある。この構造は特徴量の追加では覆らない
(F1/F2 特徴の寄与ゼロは ablation で確定済み)。

### 構造要因 5 つ

1. **土俵が最悪** — JRA 単勝は最も効率的な市場。全員が持つ公開データで、
   控除率 20% を超える差益を単勝 1 点で取るのは文献上もほぼ前例がない。
2. **意思決定時刻の断絶** — 朝 8-9 時に印・EV を確定するが、その時点で
   オッズがあるのは 57.5%、鮮度条件を満たす市場人気加点は **0/367 で不発**。
   印は市場盲目、EV は壊れた値。backtest は確定オッズで市場ブレンドする
   ため train-serve skew が恒常化。
3. **印と P の二重ランカー** — ◎ が最高 P でないレースが 39.2%。
   「何を信じればいいのか」が出力自体の中で分裂している。
4. **EV/Kelly が anti-predictive** — モデル確率の過大評価がそのまま高 EV
   として現れ、高 EV ほど回収が低い逆選択 (2026-06-14 確証、min_kelly 撤廃済)。
5. **選定プロセスがデータを焼き尽くした** — P05 116%→34%、P12 184%→45%。
   sweep 勝者の採用→崩壊を 2 度繰り返し、2024/25/26H1 は判定に使えない
   (F3 制約(1))。

## 2. 改革の基本原理

> **「勝ち馬を当てる」をやめ、「市場価格の誤差を突く」に転換する。**

- 市場 (オッズ) は敵ではなく**ベースライン**。確率は
  `p = market_implied × exp(residual)` の形でしか主張しない。
  residual = 0 なら市場と同じ = 回収 79% が保証される下限になる。
- 残差の情報源は「市場がまだ織り込んでいないもの」に限る:
  オッズの時間変化 (ドリフト・資金流入の遅速)、朝→直前の順位乖離、
  当日馬場バイアス。**静的な過去走特徴は市場が既に織り込んでいる**
  (診断 1 がその証明)。
- 意思決定は**購入可能時刻 (T−10) に、その時点のオッズで**行う。
  朝の HTML は「読み物」であって「判断」ではない。

これは既に合意済みの **F3 設計そのもの**である。本改革案の新規性は
「F3 を数ある改修候補の一つ」から「**プロジェクトの唯一の幹**」に格上げし、
それ以外の精度向上施策 (特徴追加・重み調整・sweep) を幹に従属させる点にある。

## 3. 五本柱

### 柱 1: 意思決定時刻改革 — T−10 が唯一の判断時刻
- `predictor/pit_gate.py` (T−10、実装済) を予想**生成**にも適用し、
  開催日の各レースについて T−10 時点の再計算を行う経路を作る。
- 朝 HTML は「プレビュー」と明記し、EV・買い候補は T−10 出力にのみ載せる。
  (現在サスペンド中の買い候補は、復活するなら T−10 出力側でのみ復活する)
- 前提となる収集系は本日 (2026-08-22) 復旧済み: watchdog + 日付別ログ +
  Discord 通知。**収集系の稼働率は F3 の生命線** — 8/16-8/22 の 6 日間停止は
  F3-b 蓄積 (dev 窓) を直撃した事故であり、再発 = 改革全体の遅延。

### 柱 2: モデル標的改革 — F3 Phase 1 残差オフセットモデル
- F3 設計 §4 の実装契約どおり: `log(q)` 固定オフセット + 残差特徴 x_i、
  `win_probability` 単一値の廃止 (出力スキーマ分離)。
- 残差特徴の第一候補 (dev 窓で選抜): 単勝オッズドリフト
  log(朝/T−10)、モデル順位 vs 市場順位の乖離とその時間変化、
  overround 変化、資金集中度の変化。
- Phase 1 readiness (2026-07-26 計測) ではドリフト計算可能レースが 27.4%。
  収集復旧 + 朝アンカー (keiba-morning-odds、稼働中) で蓄積率は改善傾向
  (+0.204 rate/週)。**蓄積こそが律速** — モデリングを急がず、まず貯める。

### 柱 3: 出力物改革 — 印と P の統一
- 印 (◎○▲△☆) を**残差モデルの p ランカーに統一**する (現行のルール
  スコアランカーは廃止候補)。「◎ ≠ 最高 P が 39.2%」の分裂を解消。
- ルールスコアの根拠文 (「同距離複勝N回」等) は読み物としての価値があるので
  rationale 表示は残すが、順位決定には使わない。
- 移行時は paired backtest (旧印 vs 新印) で回収率・的中率の差を必ず取る。

### 柱 4: 検証統治 — データを二度と焼かない
- **封印判定は 1 回だけ** (F3-c、dev=7/4〜9/30 / 封印=10/1〜 / ≥800 レースで判定)。
  判定基準は事前宣言済み: 封印窓 OOS 回収率 **CI 下限 > 100%** で実弾候補、
  mining 除外 ablation で寄与が残ること。
- 実弾投入の条件は CI 下限 > 100% **のみ**。点推定や「robust そう」では
  上げない (P05/P12 の教訓を制度化)。
- サスペンド中も前向き紙運用記録を絶やさない:
  `build_daily_results.py` に **would_be_candidate 列** (サスペンド無視の
  仮想判定) を追加し、フィルタ再選定の判断材料を貯め続ける。
- 四半期ごとの再選定 (`filter_sweep --recent-3fold`、鮮度ゲート付き) と
  weekly_monitor の Brier 監視は現行どおり継続。

### 柱 5: 撤退規準の常設 — 改革自体にも kill criteria
- **F3 封印判定が不合格なら、「JRA 単勝市場で公開情報から市場残差は取れない」
  を確定知見として受け入れる**。その時点の分岐は 2 つだけ:
  (a) 観察・研究プロダクトとして完成度を上げる (収益主張を恒久的に放棄)、
  (b) 私有情報源 (パドック・調教の独自定量化等) の獲得に投資する。
  「もう一周 sweep を回す」は選択肢に含めない。

## 4. やらないこと (反証済み・禁止リスト)

| 施策 | 却下理由 |
|---|---|
| 3連単等 exotic への拡張 | deep-research (2026-06-28) で無効と確証。控除率がさらに高い |
| FLB de-bias 単独 / CLV 単独 | 同上、単独では無効 |
| naive Benter 二段ロジット再ブレンド | 2026-06-28 に実装・反証済み (EV anti-predictive を解消せず) |
| min_kelly / EV 閾値の復活 | anti-predictive 確証済み。復活には確率校正の根本改善が前提 |
| 通年 sweep 勝者の一発採用 | P05/P12 の崩壊 2 例。recent-3fold + 事前宣言基準のみ |
| 静的特徴の追加 (血統・脚質系の深掘り) | F1/F2 ablation で寄与ゼロ確定。市場が織り込む情報の再発明 |

## 5. 期待値の階段 (誠実版)

| Stage | 定義 | 状態 |
|---|---|---|
| 0 | 価値破壊を止める (壊れた推奨を出さない) | **達成** (2026-08-22 サスペンド) |
| 1 | 市場追従に並ぶ: ◎ベタ 65% → **79%** | 柱 2+3 (残差 p ランカー) の直接目標。residual=0 でも達成される設計 |
| 2 | 控除率の内側で市場に勝つ: 85〜95% | ドリフト特徴が実際に情報を持つ場合のみ |
| 3 | CI 下限 > 100% (実弾候補) | F3 封印判定 1 回のみ (2026 年 12 月頃)。**確率は低い**と明記する |

Stage 3 の見込みは文献的にも低い。ただし本改革の価値は Stage 3 の成否に
依存しない: Stage 1 は設計上ほぼ保証され (市場をベースラインにするから)、
Stage 2/3 は「取れるか取れないかを 1 回の封印判定で言い切れる」こと自体が
成果物である。

  PIT ゲート T−10) は全て本案に内包。矛盾時は F3 側が優先。
