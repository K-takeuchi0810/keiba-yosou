# Phase 0.5-5 Group A — 主検定の結果 (2026-10-06)

**判定: `PRIMARY_INCONCLUSIVE` (理由 `mde_above_beta_target`)**。この区分は主検定の **前** に、検出力の固定 (結果を読まない計算) で確定した。

## 意味 (読み違えないこと)

- これは「Group A (走破時計の内容で能力を評価する特徴) に、市場に加える情報が無い」という結論 **ではない**
- 「今の標本 (2025 年 3,330 レース) と S の作り方では、事前に意味があると定義した効果 (β_target = ln(1.25)/2 ≈ 0.112、学習期の
  1 SD あたり) を判別できない」という結論である
- **判別できなかった主な原因 (2026-10-06 prediction-logic の指摘で訂正)**: S を全体で標準化したので、S の分散の大半がレース間 (クラスの差など)
  に回り、条件付きロジットが使う **レース内の分散** が小さかった。市場の確率で重み付けたレース内の分散は 1 レースあたり **0.26**
  (power.json の情報行列 866.5 ÷ 3,335)。市場との相関で失うのはその約 2 割 (シューア補元 0.26 → 0.21) で、従の原因。事前登録 §8-7 の
  見込み (レース内の分散 0.4〜0.85、MDE 0.063〜0.092) に対し、実測は 0.26 / MDE 0.134。初稿の「市場との相関 ≈ 0.5 が条件」という書き方は
  主因を取り違えていた
- **仮に点推定が真でも、今の購入条件には小さい**: β = 0.049 なら +2 SD の馬でも比 exp(0.098) ≈ 1.10 で、購入条件の 1.25 に届かない
  (比 1.25 には S ≥ 4.6 SD、140% 級の比 1.75 には S ≥ 11.4 SD が要り、2025 の行ではほぼ 0 頭)。§8-7 の 140% 級の楽観側の目安 β ≈ 0.28 は
  99% 区間の上限 0.145 の外にある。**段階は観察用のまま** (購入の候補にしない)
- 主検定の 99% 区間 [−0.051, +0.145] は 0 も β_target も含む。下限は 0 以下なので、仮に検出力の規則が無くても `PRIMARY_PASS` にはならない
- 2025 は 0.5-4A / 4B の早期停止・選択に使った年なので、新しい OOS の証拠とは呼ばない (事前登録 §8-4)

## 補足 (2026-10-06 の 4 名レビュー)

- **同着の件数**: 事前登録 §8-4 の「2025 で 6 レース」は障害 1 (track_type_code 54) を含む数。平地に限ると 5 で、主検定で除いた 5 と一致
- **sha256 の読み方**: 錠・結果に記録した固定のファイルの sha256 は、Windows の `core.autocrlf = true` の作業ツリー (CRLF) のファイルの値
  (例: config.py は LF の blob と値が違う)。LF の環境で再現するときは、同じ設定で checkout するか git の blob の hash で突き合わせる
- **§8-8 の封印窓の判定日**: 主検定が通過しなかったので、封印窓は再開せず、判定日の決定は **保留** (黙って飛ばしていない)。参考の件数: β_target の
  仮定で比 ≥ 1.25 の馬は 2025 年 3,335 レースで 97 頭 (100 レースあたり 2.9 頭) → 100 点に約 1 年、1,500 点 (MONEY_PASS の条件) に約 15 年。
  単一の群でこの大きさの効果では金額の合格に構造的に届かない。C′ でも実行の前に同じ計算をする
- **β_market = 0.867** (確定市場) は 1 ではない。金額の試験の P_new の定義 (β_market = 1 の仮定) との不一致は、C′ の金額の試験の前に固定する
- 2025 の確定オッズは買えない価格で、T−10 のずれは別のコスト (§8-7 のとおり)
- primary の来歴の `git_dirty: true` は、この実行が 2025 を読む前に書いた開始の印 (`PRIMARY_RUN_1_STARTED.json`、未追跡) だけによる。
  固定のファイルの照合は開始の印を書く前に通っている
