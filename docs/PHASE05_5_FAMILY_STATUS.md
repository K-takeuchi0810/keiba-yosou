## 4. 次の世代の候補 (この族の主検定ではない)

外部の指示者の決定 (2026-10-06):

- **A″** (A の時計の情報を pooled within-race SD の単位で表し直す): A の 2025 の結果・検出力の不足の原因・C′ で別の標準化が効いたことを
  見た後に生まれた仕様なので、同じ 2025 で走らせても新しい確証の証拠にはできない。**次の世代の探索的な再開発** として、2022-2024 で作り、
  必要なら消費済みの 2025 で 1 回だけ診断として通すことはできるが、PASS として扱わず、将来の新しい封印窓に持ち越す候補にする
- **通過順位版の Group C**: C′ の救済として 2025 の主検定を足さない。学習期の条件 (通過順位から推定した脚質の κ > 0.31 /
  通過順位の pace_pressure で §2 C の反証の条件に該当しない / 脚質の主効果を局外の列に入れる / 主検定の年と多重比較を先に固定) を
  満たした場合だけ、新しい事前登録の候補にする
- 族が終わった後の優先順は A″ → 通過順位版の C (A″ は能力の尺度を条件付きロジットに合う単位へ直す修正で、実装と検出力の設計が明確なため)。
  いずれも新しい窓なしでは確証にしない
