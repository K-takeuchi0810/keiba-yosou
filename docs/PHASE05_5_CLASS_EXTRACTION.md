# Phase 0.5-5 Group A — クラス (競走条件コード) の抽出の仕様 (2026-10-05)

`docs/PHASE05_5_PREREG.md` §8-4b の補正テーブルの「クラス」の元データを作る手順。DB の `races` には競走条件コードの列が無い
(2022-2024 の平地の JRA 9,987 レースのうち 7,243 は一般競走で `race_name` が空、`grade_code` は重賞・L・特別しか区別しない)
ので、raw の RA レコードから **Group A 専用の凍結した表** を作る。外部の指示者の決定 (2026-10-05、選択肢 1a)。

## 範囲 (やらないこと)

- DB・schema・`jvlink_client/parser.py` (共有の parser) は変えない。抽出のロジックは Group A 専用の script の中に閉じる
  (共有の parser に足すと ai-builder が import する経路が変わるため)。→ `ai_builder_impact: none`
- DB に書かない。raw は読み取りだけ

## 凍結する表 (`data/backtest/group_a_class_20261005/`)

- 1 行 1 レース: `race_id` (`年月日_場_回_日_R`)、**raw の条件コード 5 つ** (位置 623 / 626 / 629 / 632 / 635 のそのままの 3 文字)、
  `canonical_class`、出典の raw のファイル名、そのファイルの sha256
- MANIFEST: 抽出 script の Git SHA と sha256、`mapping_version`、対象期間、件数、使った raw のファイルの一覧と sha256、表の sha256
- **canonical class** (`mapping_version = class_v1`): 最若年条件 (位置 635) の値を、次の 6 つの **カテゴリ** に写す。
  数値としての大小関係は仮定しない (補正テーブルではカテゴリの水準として推定する)
  - `701` 新馬 / `703` 未勝利 / `005` 1 勝クラス / `010` 2 勝クラス / `016` 3 勝クラス / `999` オープン (リステッド・重賞を含む)
  - これ以外の値は **止める** (黙って別のカテゴリに寄せない)。同じレースに raw の値が複数あって食い違ったら止める
- 最若年条件を正本に選んだ理由: Group A のクラスの補正は「そのレースの水準」が要るので、出走できる最も若い馬の条件が
  レースの条件を表す (仕様書の説明)。他の 4 つの欄も raw のまま残し、年齢の欄ごとに値が違うレースの件数を MANIFEST に書く

## 手順 (固定)

1. 対象を先に固定する (`TARGETS.md`、3 開催日の全レース)
2. JRA 公式の値を先に固定する (`expected_jra_official.py`、出典と取得時刻)
3. raw から抽出し、対象と完全一致することを確かめる (`python -m scripts.group_a_class_table probe --raw-dir <raw>`)。
   1 レースでも食い違えば凍結しない
4. 2021-01-01〜2025-12-31 の JRA の全レースの表を作って凍結する (2021 は 365 日窓の過去走のため。2025 は主検定の対象レース
   のため。**補正テーブルの推定に使うのは 2022-2024 だけ** で、表を作ることは推定ではない)
5. 表の利用は Group A の補正テーブルの推定と、過去走の評価値の算出だけ

## 表の範囲と、利用側の絞り込み (2026-10-05 レビューの反映)

- 表は **JRA の全レースの超集合**: 障害 (`track_type_code` 51 以上) と中止 (`data_div = 9`、2021-2025 で 15 レース) を含む。
  利用側 (Group A) が、DB の `races.data_div = 7` と平地で絞る。MANIFEST には全体の集計と `data_div 7` だけの集計の両方を出す
- 止める条件: 空の raw / 短いレコード (707 バイト未満) / 想定外の最若年条件コード / 同じレースで条件コード・距離・コースの食い違い。
  全行を検証してから原子的に書く (止まったときに半端な表を残さない)
- MANIFEST には build の時点の HEAD・作業ツリーの未コミットの変更の有無 (`git_dirty`)・script と parser の sha256・argv・
  読んだ / 飛ばしたレコードの件数を残す。script と期待値のファイルは `.gitattributes` で `eol=lf` に固定する
- canonical class のカテゴリを足すときは、`MAPPING_VERSION` を上げ、この文書・`TARGETS.md` の写像・期待値の docstring も直す
- parser の private な `_split_fixed` に依存する (名前が変われば、最初の呼び出しで AttributeError で止まる。黙って壊れない)

## クラスの補正の意味 (外部の指示者の決定 2a、`PHASE05_5_PREREG.md` §8-4b に明文化)

クラスの効果は **馬場差 (track / day variant) の推定のための局外の補正 (nuisance adjustment) としてだけ** 使い、馬ごとの
評価値からクラスの水準を直接引かない。
