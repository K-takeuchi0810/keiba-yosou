# Phase 0.5-5 Group C′ — 主検定の結果 (2026-10-06)

**判定: `PRIMARY_FAIL` (理由 `ci_lower_not_above_zero`)**。主検定の前に検出力で `PRIMARY_DECIDABLE` (MDE 0.066 < β_target 0.112) を確定し、
その後に 2025 で 1 回だけ実行した。

## 1. 統計の結論 (primary statistical conclusion)

- 主検定 (2025、確定市場、`[log P_market, S]` の条件付きロジット): **β_S = −0.0183、99% 区間 [−0.0676, +0.0328]** (レース単位の
  ブロック・ブートストラップ、5000 回・seed 20261004、捨て 0、valid)
- 99% 区間の下限 ≤ 0 → `PRIMARY_FAIL`。区間は β_target 0.112 を大きく下回る側にあり、**事前に意味があると定義した大きさの効果
  (β_market = 1 のとき S が 2 単位違う 2 頭の相対オッズに 1.25 倍の差) は、検出できる設計で否定された**
- 点推定は負 (期待と逆向き) だが、区間は 0 を含む。「逆向きの効果がある」とも言わない
- 憲法の 140% 級 (比 1.75、β ≈ ln(1.75)/2 ≈ 0.28) は 99% 区間の上限 0.033 の約 8.5 倍の外にある
- 2025 は Group A に続く 2 回目の再利用で、0.5-4A / 4B の選択にも使った年なので、新しい OOS の証拠とは呼ばない
  (`config.CONSUMED_WINDOWS` に記録)。2 回目だから独立の新しい証拠が増えたとは解釈しない

## 2. 仕組みの解釈 (mechanistic interpretation)

**固定した C′ の S (脚質コード版) には、市場に対して検出できる追加の情報がなかった。pace × メンバー構成の仮説を支持する証拠も得られなかった。**
主検定の前に台帳に固定した解釈の規則どおり、次を併記する (いずれも主検定の判定を変えない):

- **事前登録 §2 C の反証の条件に、学習期で既に該当していた**: pace_pressure の高いレースの先行馬の 実勝利数 / Σ P_market = 0.999
  (1,899 / 1,900.6)。市場は pace 帯 × 前後で ±0.6% 以内に校正済みだった
- **脚質の推定 (過去 5 走の最頻値) の精度が低い**: 当日の脚質との一致 前後の 2 分類 68.5% (常に「後」の基準 65.7%、κ 0.31)
- **S はレース内で脚質の主効果 (先行・差し) とほぼ同じ** (相関 0.92)。pace の交互作用に固有の分散は 1 − r² ≈ 0.15 (約 1.5 割)
- 前・後の 2 分類では市場は ±0.6% 以内に校正されていたが、学習期の 4 分類では 追込 の 実勝利 / Σ P_market が pace の帯を問わず 0.954〜0.990、
  差 が 1.000〜1.026 と、**脚質の主効果の側に 3〜5% の偏りの痕跡** がある (`diag/hypothesis_diagnostics.json`)。これは C′ の検定の対象外
  (C′ の S は主効果を対象にしていない) で、C′ の救済にも使わない。新しい事前登録の候補の仮説として記録するだけ (2025 を読まずに得た診断)
- 「仮説が違う」と「作り方 (脚質コードの測定の弱さ) が悪い」は区別できない。仮説の再検定は通過順位 (corner) に基づく本来の Group C で行う
  (C′ の中で脚質の推定の窓・走数・最頻値の変種は試さない)
- **FAIL の後に副次の記録の一部の結果を拾って C′ を救済しない** (副次の診断で読み分けるのは PASS の場合だけ、外部の指示者の決定)
