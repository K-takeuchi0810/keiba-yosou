# 本番モデルはオッズに無い情報を持っているか (2026-09-15)

## なぜこの検証をしたか

ユーザ指摘: **「オッズ中心で考えることをやめるべき。どの特徴量に対しても偏りなく
考える必要がある。オッズは人間が作り上げたただの指標に過ぎない」**

それまでの検証はすべて「**この特徴はオッズに情報を足せるか**」という形で、
オッズを常に基準側に置いていた。この枠組みでは、オッズと同じ情報を持つ特徴は
自動的に「情報なし」と判定される。そして一度も測っていない数字があった:
**オッズを使わない予想は単独でどれだけ当たるのか**。

## 方法

オッズと実績を **対等な 2 つの推定器** として扱う (Benter 方式):

1. それぞれ確率を出す
2. **レース内で合計 1 になるよう正規化**する
3. 2 段目 (ロジスティック回帰) に `log(実績確率)` と `log(市場確率)` を渡し、
   **どちらをどれだけ信じるかをデータに決めさせる**
4. 未知期間で判別力を比べる

実績側の重みがゼロなら、その予想は市場に無い情報を持っていない。

## 結果 1: 特徴を混ぜるのは誤り

急造の実績モデル (20 特徴、PIT 厳守) で、未知期間 2026-07〜09 (10,094 頭):

| | AUC |
|---|---|
| 実績だけ (オッズ・人気を一切使わない) | 0.7515 |
| オッズだけ | 0.8371 |
| **特徴を全部 1 つのモデルに混ぜる** | **0.8296** |

**特徴を混ぜるとオッズ単独より悪化する**。従来の検証で「オッズが最良」と
出ていたのは、この混ぜ方をしていたため。**手法の誤りであって、結論ではなかった**。

正しく 2 段結合すると:

| | |
|---|---|
| 2 段目の重み | 実績 **−0.018** / オッズ **+1.198** |
| 結合後 AUC | 0.8372 (オッズ単独 0.8372 と同一) |

## 結果 2: 本番モデル (112 特徴) でも同じ

`PRED_DISABLE_BLEND=1` で市場ブレンドと割引を全段バイパスした純粋な予測確率を
613 レース分 (2026-07-04〜09-13、T-10 PIT 再構成 + 発走後列マスク) 抽出。

**2 段目が学習した重み**

| | 重み |
|---|---|
| 本番モデル (実績) | **−0.130** |
| オッズ (市場) | **+1.421** |

期間を入れ替えると実績 **+0.035** / オッズ +1.243。**符号が反転するほど小さい**。

**判別力 (未知期間 2026-08-17〜09-13、3,452 頭・勝ち 261)**

| | AUC |
|---|---|
| 本番モデルだけ | 0.7830 |
| オッズだけ | **0.8247** |
| 2 段結合 | 0.8244 |

## 結果 3: 食い違ったときに勝てるか (最も重要な比較)

「モデルと市場が食い違ったときに買う」線を、**同じレースで 1 番人気を買った場合と
対応させて**比較した。これが経済的に意味のある唯一の比較。

| | n | 回収率 | 95% 区間 |
|---|---|---|---|
| 全レースで 1 番人気 | 613 | 84.8% | [74.4%, 95.2%] |
| 一致時: モデル = 1 番人気 | 356 | 82.9% | [70.1%, 95.8%] |
| 食い違い時: モデルの馬 | 257 | 87.5% | [62.4%, 112.7%] |
| 食い違い時: 1 番人気 | 257 | 87.3% | [70.0%, 104.6%] |
| **差 (対応比較)** | 257 | **+0.2pt** | **[−33.8, +34.3]pt** |

前日に「有望」とした「印 1 位かつオッズ 5 倍以上で回収 112%」は、同じ現象を
別の切り口で見たもので、**正しい対応比較では消える**。

## 何が言えて、何が言えないか

**言えること (検出力が十分)**
- 本番モデルの並べ方は **オッズの並べ方より明確に劣る** (AUC 0.783 vs 0.825、3,452 頭)
- 2 つを正しく結合しても、実績側に意味のある重みは付かない

**言えないこと (検出力が不足)**
- 食い違い時の差は区間が **±34pt** もあり、**仮に 30pt の優位があっても検出できない**。
  「差が無い」ことを示したのではなく「差を見つけられなかった」だけ。613 レースでは足りない。

## 未解明の問い

この検証が示したのは「**今のモデルでは足りない**」であって「原理的に無理」ではない。
Benter が香港で成功したのは大衆より強い基礎モデルを持っていたからで、
弱いモデルで重みがゼロになるのは当然とも言える。

> **どれだけ強い実績モデルなら、2 段目が重みを与え始めるのか**

現状: 実績 AUC 0.783 / 市場 AUC 0.825 → 重み ≒ 0。
この境界を測ることが次の問い。

## 付随して分かったこと

オッズ側の係数が **+1.2〜+1.4 と 1 を超える**。市場の含意確率を増幅すべき
= **本命が過小評価されている** (人気薄が買われすぎ) という補正。ただしこれは
レース内の順位を変えないので「どの馬を買うか」は変わらず、本命ベタが
78.5% しかない以上、これ単独では控除率を超えない。
