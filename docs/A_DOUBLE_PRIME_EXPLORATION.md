## A2-1. 候補の門 (外部の指示者の決定 2026-10-06、A″ を見る前に固定)

これらの閾値は、A″ の値を見る前に、Group A / C′ / D から得た方法論の教訓 (標準化の単位・主効果の言い換え・件数の見込み) を使って
設定した **次の世代の開発の門** である。A″ の結果を見て動かさない。

| 門 | 条件 (満たさなければ) | 測る行 |
|---|---|---|
| **Construct** | レース内回帰 `S ~ 前走の着順の分位` の決定係数 < 0.80 (≥ 0.80 なら `STRUCTURAL_REJECT`) | 2024 の行 (合成は 2022-2023 で当てはめ、E2 と同じ) |
| **Sign stability** | E1 の 2 向きと E2 の計 3 本の β_S のうち 2 本以上が正 / z ≤ −2 が 0 本 / 最終の 2022-2024 pooled の当てはめで β_S > 0 (どれかを満たさなければ `SIGN_INSTABILITY_REJECT`) | E1・E2・pooled |
| **Identifiable variation** | 2024 の行の、市場で重み付けたレース内の S の分散 (レースに等しい重みで平均) ≥ 0.50 (未満なら `INSUFFICIENT_WITHIN_RACE_VARIATION`) | 2024 の行 (合成は 2022-2023) |
| **Primary feasibility** | `N_calendar_required = ceil(N_primary_required / r)` ≤ 6,800 確定の平地 JRA レース (> 6,800 なら reject) | 2024 の行 |
| **Money maturity** (reject しない) | 2024 の `ratio_buys_at(rows, 1, β_target)` の購入率から、1,500 点に要するレース数 ≤ 17,000 → `MONEY_MATURABLE` / > 17,000 → `MONEY_UNTESTABLE_WITHIN_5Y` / 2024 の購入候補が 0 件 → `MONEY_UNTESTABLE_NO_EXPECTED_BUYS`。主検定の前に固定し、後者 2 つなら主検定が PASS しても「収益性まで確認できる候補」とは呼ばない | 2024 の行 |

- 背景 (閾値の設定の材料として開示): 市場で重み付けたレース内の分散は Group A 0.26 / C′ 0.83。Group D は S が前走の評価値の言い換え
  (レース内の決定係数 0.93) で停止
- **記録するが門にしない (診断)**: S と log P_market のレース内の相関、`S ~ 前走の着順の分位 + log P_market` の決定係数 (市場との重なりは
  Construct の失敗ではなく、検出力 (Primary feasibility) が評価する)、年別・pooled のレース内の分散
- `N_primary_required` (規則 §4): 2024 の行で、結果を読まない Fisher の SE (β_market = 1・β_S = 0) と、学習期のブートストラップの SE
  (2022-2023 の当てはめで 1000 回・seed 20261004) を 2024 のレース数に換算した値の大きい方から σ₁ (1 レースあたり) を出し、
  `N = ceil((3.4174·σ₁/β_target)²)`。r = 2024 の A″ の解析対象のレース数 ÷ 2024 の確定の平地の JRA レース数
- 門の判定はすべての量が出た後に 1 回行い、台帳に書く。門で落ちたら窓は開けずに捨て、通過順位版の C へ回す

## A2-2. 手順

構造の量 (E0) → 実装・変異 → E1 (2022 ⇄ 2023) → コミット → E2 (2022-2023 → 2024 の dry run) → コミット → 最終の pooled の当てはめ
(2022-2024) → 検出力・件数 → 候補の門の判定 → レビュー

- 尺度を推定する期間 (§8-4c-2 と同じ): E1 は当てはめの側の年だけ / E2 は 2022-2023 / pooled は 2022-2024
- 構造の量 (E0) は結果の列を使わない (S は 2022-2023 で当てはめた合成で作り、2024 の行で測る。合成の当てはめ自体は学習期の結果を使う)。
  実装の都合で E0 は実装・変異の後に計算する (結果を見る順序は E0 → E1 → E2)
