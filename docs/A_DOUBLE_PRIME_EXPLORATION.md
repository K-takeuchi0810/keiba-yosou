### 判定の後のレビュー (3 名、2026-10-06) で追記した記録 (判定は変えない)

- **判定のファイルの作り直し**: 最初の `gate/gate_verdict.json` は手で `gate_verdict` を呼んだ結果で、入力と来歴が無かった (code-quality の
  must-fix)。`--mode verdict` (e0 / e1 / e2 / gate の成果物を読み、入力・各ファイルの sha256・来歴を同梱) で `verdict/verdict_result.json`
  を作り直し、手の版は削除した。判定は同じ `SIGN_INSTABILITY_REJECT`
- **件数の訂正**: コミット `c9002d6` のメッセージの「テスト 18 本」は 17 本 (関数 14 + パラメタ化 4 ケース) だった (履歴は書き換えない)
- **合成が年で入れ替わる構造の理由** (prediction-logic の診断を自分で再計算して一致): 2022 の行の標準化した成分のレース内の相関は
  best3–rank_in_race **0.865** (rank は best3 のレース内の順位そのもの)、last–best3 0.722 (last と best3 が同じ値の行 12.4% = 窓に 1 走)、
  trend は best3・rank とほぼ直交 (−0.02)。4 成分は実質 2 因子 (水準と勢い) で、同時の当てはめでは best3 と rank の個別の係数が識別されず、
  「逆符号は 0」の規則が年ごとに **別の S** を選んだ (2022 の当てはめ = rank だけ、2023 = best3 + trend)。E1 の 2 向きは同じ候補の比較に
  なっていなかった。ただし reviewer の診断では、成分を単独で使っても、4 成分を等しい重みで合成しても、学習期 3 年の評価で β の符号は
  定まらなかった (例: 等重みの合成 +0.055 / −0.016 / −0.003)。これらは救済にも仕様の変更にも使わない
- **符号の門の性質** (validation): 3 本は独立でない (2022 ⇄ 2023 は同じ 2 年の役割の入れ替え、E2 も同じ年で当てはめる)。各本の SE
  0.022-0.027 に対し、β = 0 ならおよそ半分の確率で通り、β = β_target ならほぼ確実に通る門である。落ちたことが言えるのは「β_target 級の
  安定した正の効果とは整合しない」までで、有意性の検定ではない
- **ブートストラップの性質**: 学習期のブートストラップは、同じ 2022-2023 の行で当てはめた凍結の S を再標本化しており、合成の重みの推定の
  ばらつきを含まない (今回は Fisher の SE の方が大きく、判定に影響しない)
- **レース内の分散 0.523 は境界**: 閾値 0.50 のすぐ上で、合成の構成によって 0.52-0.74 と動く量 (E1 の 2 向きで 0.743 / 0.580)
- **S の尺度の細部**: S_raw の σ_within の平均には、全成分が欠損のレース (2022-2023 で 603、全頭 0) が v = 0 で入る (成分の σ は欠損でない
  レースだけ)。β の 1 単位が成分の規則と約 5% ずれる。分散の門の値には効かない
- **E1 の成分の観測率**: 単年の補正テーブルでは評価値の付かない走が多い (2022 だけで当てはめると 19,760、2022-2023 では 4,554)。E1 と E2 の
  成分の観測率は同じではない
- **件数の見込みが小さい構造の理由** (C′ は 100 レースあたり 70 頭、A″ は 0.6 頭): 比の基準はレース内の **市場で重み付けた** 平均で、S と市場が
  正の相関 (0.42-0.56) なので、基準が人気馬の S の水準まで上がる。等しい重みの平均から +2 を超える行は約 1.6% だが、市場で重み付けた平均から
  +2 を超える行は 0.08%。加えて約 11-12% の行がレース平均で埋められ、約 9% のレース (新馬など) は全頭 0。C′ は S と市場が負の相関で、
  1 つの区分が丸ごと +2 単位に乗るカテゴリの分布だった。β_target = ln(1.25)/2 を固定する限り、連続で市場と正の相関を持つ候補の件数は
  構造的に小さい。購入の候補の市場確率の中央値は 0.03-0.06 (16-33 倍)

### 通過順位版の C への引き継ぎ (次の候補の事前登録で必ず扱う)

1. **合成の重みを学習期の条件付きロジットで決めない**: 事前に固定した重みか単一の成分にする。合成するなら、成分のレース内の相関行列と、
   成分ごとの単独の leave-one-year-out の符号を **門の前の必須の記録** にする (C′ の `single_component_fits` / `component_within_corr` を
   A″ は落としていた)
2. **符号の門に大きさの条件を入れる**: 今の門は β = 0 でも約半分通る。例: 各本の z > −1 かつ leave-one-year-out の pooled の z ≥ 1、
   または符号の一致率の帰無の分布を明記する。C の台帳を開く前に外部の指示者と決める
3. **符号の事前を成分ごとに機構から決める**: 「全成分の期待符号は正」とせず、市場の偏り (例: 直近の走への過剰反応) の機構から決める
   (A″ の同時の当てはめでは last の係数が 4 回とも負 — 証拠ではないが材料)
4. **件数の見込みと候補の市場確率の分位を早めに記録する**: 連続の候補は件数が構造的に小さいので、主検定の候補にする前に見込みを確かめる
5. **来歴に実行の開始時刻と開始時の HEAD を残す** (`scripts/prereg_runner.provenance` の拡張、次の候補の runner から)
